# Courseday Brand Styling

## Overview

Courseday is a multi-tenant golf course operations platform. Its visual identity is calm, professional, and nature-grounded — forest greens, warm sandy tones, and clean typography.

**Keywords**: branding, corporate identity, visual identity, post-processing, styling, brand colors, typography, Courseday brand, visual formatting, visual design, golf, operations

## Brand Guidelines

### Colors

**Brand Colors (Light Mode):**

- Forest Green (brand primary): `#1f5d3a` — primary UI, buttons, badges
- Warm White (brand foreground): `#faf9f0` — text on green backgrounds
- Light Green (brand soft): `#eff5f1` — subtle green-tinted backgrounds, hover states
- Dark Green (brand ink): `#1a3327` — deep green for high-contrast text on light

**Neutral / Surface Colors:**

- White (background): `#ffffff` — page background
- Near Black (foreground): `#23232d` — primary body text
- Off-White (surface soft): `#faf8f2` — warm off-white card surfaces
- Light Gray (border): `#e8e8ed` — dividers, inputs

**Accent Colors:**

- Sand: `#d5c394` — warm tan, secondary accent (e.g. highlights, tags)
- Sand Dark: `#3c2f18` — text on sand backgrounds

**Semantic Colors:**

- Success: `#3a8c60` — positive states
- Warning: `#c9a63a` — caution states
- Destructive: `#d4503a` — errors, delete actions

### Typography

- **Display / Headings**: Fraunces (variable serif; with Georgia fallback) — used for large titles, hero text, logotype
- **UI / Body**: Geist Sans (with system-ui, sans-serif fallback) — used for all interface text, labels, body copy
- **Code / Mono**: Geist Mono (with ui-monospace fallback) — used for code, technical data

### Voice & Tone

- Clear, direct, professional — no jargon or filler
- Golf-course-operational: practical, venue-facing language
- Calm confidence — not flashy, not corporate-cold

## Application Rules

### Typography Hierarchy

- Large display headings (hero, section titles): Fraunces
- All UI text, body copy, labels, captions: Geist Sans
- Code snippets, data tables, IDs: Geist Mono
- Never use decorative or novelty fonts

### Color Usage

- Primary actions (buttons, active states, badges): Forest Green `#1f5d3a` with Warm White `#faf9f0` text
- Page backgrounds: White `#ffffff` or Surface Soft `#faf8f2`
- Secondary / passive UI: Light Green `#eff5f1`
- Accent highlights and tags: Sand `#d5c394`
- Body text: Near Black `#23232d`
- Never use pure saturated colors — always stay within this palette

### Shapes & Borders

- Border radius: `0.625rem` (10px) — the platform default; use consistently
- Borders: Light Gray `#e8e8ed`
- Avoid sharp right angles in UI components — always round corners

### Logo / Wordmark

- "Courseday" wordmark: Fraunces, Forest Green on white or Warm White on Forest Green
- Do not add taglines or decorative elements to the wordmark
